# Security policy

Cerepath is an early-stage project. Do not expose the current starter to the public internet or use it as a multi-user service until the production security gaps in `docs/SECURITY.md` are closed.

## Reporting a vulnerability

Please do not disclose vulnerabilities in public issues or pull requests.

Use GitHub's **Report a vulnerability** feature on this repository's Security tab when available. If private vulnerability reporting is unavailable, contact the repository owner through their GitHub profile and request a private disclosure channel. Include a concise description, impact, affected version/commit and reproducible steps. Avoid accessing, changing or retaining other users' data during research.

## Response expectations

The maintainers will acknowledge reports when possible, validate the issue, coordinate a fix and publish an advisory when appropriate. Please allow time for a fix before public disclosure.

## Supported versions

Only the latest commit on the default branch is currently supported. This project has not published stable releases yet.
